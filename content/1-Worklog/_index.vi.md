Dưới đây là nhật ký công việc chi tiết của tôi qua 5 tuần thực hiện chương trình thực tập First Cloud AI Journey:

**Tuần 1:** [Tìm hiểu tổng quan kiến trúc AWS, lập tài khoản thực hành và làm quen với AWS Core Services: EC2, S3, IAM](1.1-week1/)

**Tuần 2:** [Tìm hiểu AWS Networking: VPC, Subnet, Internet Gateway và thực hành cấu hình mạng cơ bản](1.2-week2/)

**Tuần 3:** [Tìm hiểu AWS Lambda, mô hình Serverless và AWS CloudWatch (giám sát), CloudTrail (kiểm vết hoạt động)](1.3-week3/)

**Tuần 4:** [Tìm hiểu Elastic Load Balancer (ELB), Auto Scaling và AWS ECS; làm quen với kiến thức Docker cơ bản](1.4-week4/)

**Tuần 5:** [Thực hiện dự án tổng hợp trên AWS, vận dụng các kiến thức đã học và hoàn thiện kết quả thực tập](1.5-week5/)
